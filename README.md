# elpasotrafficticket.com — Astro + Cloudflare Workers

Pixel-faithful port of the WordPress/Elementor site (Oct 2026) to a static Astro build served by a Cloudflare Worker.

- `src/legacy/` — ported Elementor HTML (header, footer, pages). Generated by `ept-capture/port.py` from the live site; edit the `.html` fragments directly for content changes.
- `public/css/site.css` — bundled Blocksy + Elementor CSS from the old site (load order preserved); `inline.css` = WP inline styles; `src/styles/site.css` = our overrides and form styles.
- `src/components/*Form.astro` — replacements for the WP-FSQM / JetFormBuilder forms. They POST to the Worker (`worker/index.ts`), which emails leads via Resend; `/api/fight` creates a Stripe Checkout session when `STRIPE_SECRET_KEY` is set.
- `src/data/pricing.ts` — Fight-My-Ticket prices (carried over from the old checkout form).
- Worker secrets: `RESEND_API_KEY`, optional `STRIPE_SECRET_KEY`; vars `LEAD_TO_EMAIL`, `LEAD_FROM_EMAIL`.

Build: `npm run build` · Preview: `npm run preview` · Deploy: `npm run deploy` (wrangler).
